# Promo videos

Vertical Shorts (1080×1920, 30fps) made from **real gameplay with the game's own sound**, composed with
[HyperFrames](https://github.com/heygen-com/hyperframes). Nothing here ships to players: `index.html` is never
modified, and `/.vercelignore` keeps this folder off the site.

```bash
cd promo && npm install          # puppeteer + its headless Chrome
npm run make -- special-floors   # record missing clips -> build -> render -> renders/special-floors.mp4
```

Needs Node 20+ and `ffmpeg`/`ffprobe` on PATH. HyperFrames runs via `npx` at the version pinned in each short's `package.json`.

## Shorts

| Short | Kind | What it shows |
|---|---|---|
| `shorts/clicker` | hand-authored `index.html` | motion-graphics explainer + three framed gameplay clips (silent) |
| `shorts/floor-tour` | elevator tour (`short.json`) | six level designs: themes, desk types, boardroom boss |
| `shorts/special-floors` | elevator tour (`short.json`) | named pop-culture floors: Red Stapler, IT Crowd, Initech, Lumon, 404, C-Suite |

`npm run make -- <short>` options: `--rerecord` (re-record every clip, not just missing ones), `--no-render`
(record + build only, then preview), `--small` (also write a <30 MB copy for sharing).

Preview / edit in HyperFrames Studio: `cd shorts/<short> && npx hyperframes preview`.

## Making a new Short

Most new Shorts are an **elevator tour**: hook → floors (each introduced by elevator doors and the game's ding) → CTA.

1. **Add scenarios** in `recorder/scenarios.mjs`, e.g.
   `sales: { floor: 18, hitsPerDesk: 2, run: floorRun(40) }`.
   `floor` + `hitsPerDesk` generate a save balanced with the game's own formulas; `up` overrides upgrade levels;
   `run` is the tap script (`floorRun` for "clock in and flip", `elevatorRun` for "clear, ride up, fight the next floor").
2. **Create `shorts/<name>/`**: copy `short.json`, `package.json`, `meta.json` and `hyperframes.json` from an
   existing tour, then edit `short.json`: hook text, one beat per scenario (`floor`/`dept` go on the elevator panel,
   `dur` is how long the clip plays, `caps` are `[text, from, to]` in seconds from the beat's start), CTA text.
3. `npm run make -- <name> --no-render`, look at the clips in `assets/clips/`, adjust `dur`/`mstart`/captions,
   then `npm run make -- <name>`.

Record a single clip to look at: `npm run record -- --out /tmp/clips <scenario>`.

## How the recorder works

- `recorder/serve.mjs` serves the repo root and splices a one-line hook into the game's module script **in memory**
  (exposing desks, camera, sound effects and balance formulas), drops Vercel analytics, and answers `/api/*` locally
  so recordings never touch production stats. If the game's code moves and the hook can't be placed, it fails loudly.
- `recorder/rec.mjs` drives headless Chrome as a phone (432×768 @2.5x). A virtual clock replaces
  `performance.now`, `Date.now`, timers, `requestAnimationFrame` and CSS animations and is stepped one frame at a time,
  so clips are smooth however slowly software WebGL renders.
- Sound: every game sound is synthesized WebAudio scheduled off `AC.currentTime`, so `AudioContext` is swapped for an
  `OfflineAudioContext` whose clock follows the virtual clock. Rendering it afterwards yields the exact soundtrack,
  sample-aligned with the frames, muxed into each clip.
- Each clip's taps (time + pixel position) go to `assets/clips/taps.js`; compositions draw tap ripples from it,
  since the game shows nothing where a finger lands.
- The `bank` scenario records isolated game sounds (ding, doors, thump, flip, cadence, crit, buy, relic) for the
  motion-graphics parts.

## Generated vs committed

Committed: recorder, scenarios, scripts, template, fonts, each short's config. Gitignored and regenerated by
`make`: `assets/clips`, `assets/sfx`, `assets/fonts` copies, elevator-tour `index.html`, `renders/`.

The kaomoji fonts in `fonts/` are glyph subsets of DejaVu Sans Bold and Droid Sans Fallback. To add glyphs:
`uvx --from fonttools --with brotli pyftsubset <font.ttf> --text='(╯°□°)╯︵┻━┻…' --flavor=woff2 --output-file=fonts/kao-*.woff2`.
